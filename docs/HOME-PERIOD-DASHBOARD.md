# หน้าแรกตามวันที่และรอบเดือน

หน้าแรกเลือกวันที่ย้อนหลังได้ถึงปี 2000 และเริ่มที่วันนี้เสมอ ยอดเงินรวมคือยอดตามรายการที่ยังใช้งานอยู่จนถึงวันที่เลือก เงินที่แยกออมเป็นส่วนหนึ่งของเงินรวมอยู่แล้ว จึงคำนวณเงินเหลือใช้เป็น `เงินรวม − เงินแยกออม` โดยไม่บวกเงินออมซ้ำ

ผู้ใช้เลือกวันเริ่มรอบได้ 1–28 ค่าเริ่มต้นคือวันที่ 1 ตัวอย่างวันที่ 20 ทำให้รอบ 20 ตุลาคม–19 พฤศจิกายน รายรับ รายจ่าย และงบในหน้าแรกใช้รอบนี้ งบยังเป็นเกณฑ์เปรียบเทียบและไม่หักเงินรวม

มุมมองมี 4 ช่วง:

- รายวัน: เป้ารายวันที่ผู้ใช้ตั้งเอง (เก็บต่อผู้ใช้ใน Supabase), รายการของวันที่เลือก, สัดส่วนหมวด และรายรับ–รายจ่ายแยกประเภท
- รายสัปดาห์: อาทิตย์–เสาร์ เปรียบเทียบแต่ละวันกับสัปดาห์ก่อน
- รายเดือน: รายรับ รายจ่าย เปอร์เซ็นต์งบรวม และยอดเหลือ/เกินของแต่ละก้อนงบ
- รายปี: รายรับ–รายจ่ายของ 12 รอบ และเงินออมสะสม ณ สิ้นแต่ละรอบ

เงินคืนหักรายจ่ายของวันที่/รอบที่ได้รับคืน การโอนและการกันเงินออมไม่เป็นรายจ่าย กราฟใช้ NUMERIC จาก Supabase และแปลงเป็นสตางค์จำนวนเต็มใน client

## Manual acceptance

1. เปิดภาพรวมและตรวจว่าวันเริ่มต้นเป็นวันนี้ กดย้อนหนึ่งวันแล้วเช็กยอดและรายการ
2. ตั้งรอบเป็นวันที่ 20 ตรวจช่วงวันที่บนบัตรและสรุปรายรับ–รายจ่ายในรอบ
3. เปิดรายวันทั้ง 3 แถบ ตรวจมิเตอร์ รายการ pie chart และประเภทรับ–จ่าย
4. เปิดรายสัปดาห์ ตรวจว่ามี อา.–ส. และสองชุดข้อมูล
5. เปิดรายเดือน ตรวจยอด `ใช้ / งบ`, เปอร์เซ็นต์ และยอดเหลือหรือเกินรายก้อน
6. เปิดรายปี ตรวจกราฟรับ–จ่ายและเส้นเงินออมทั้งบนมือถือและเดสก์ท็อป
7. ปิดเครือข่ายแล้วเปลี่ยนวันเริ่มรอบ ต้องไม่แสดงว่าบันทึกสำเร็จ

การทดสอบอัตโนมัติครอบคลุมสิทธิ์ authenticated/anonymous/ข้ามผู้ใช้ รอบวันที่ 20 เงินคืน เงินออมไม่บวกซ้ำ 7 วันเต็ม การเลือกวันที่อนาคต และ responsive Playwright ทั้งสองขนาด

## แก้รายการจากรายวัน

แตะรายการรับ–จ่ายใต้มิเตอร์เพื่อเปิดรายละเอียด แล้วเลือกแก้ไข ลบ หรือดูประวัติ ระบบอ่านรายการล่าสุดด้วย ID ภายใต้ RLS และกรองเจ้าของก่อนเปิด จึงรองรับวันที่ย้อนหลังต่างจากเดือนของหน้ารายการด้วย การแก้ไขใช้คำสั่งเดิมพร้อม version และประวัติ ยอดและกราฟโหลดใหม่หลังยืนยัน โดยคงวันที่ที่กำลังดูไว้ เงินคืนยังใช้วิธีลบแล้วบันทึกใหม่ตามข้อจำกัดเดิม

ตรวจด้วยมือ: เลือกวันในเดือนก่อน แตะรายจ่าย เปลี่ยนยอดแล้วบันทึก ตรวจยอดใหม่และวันที่เดิม จากนั้นทดสอบรายรับและปุ่มประวัติ หากเปิดรายการไม่ได้ต้องมีข้อความแจ้งและไม่มีหน้าต่างแก้ไขค้าง

## หน้าแรกแบบกระชับและเป้ารายวันส่วนตัว

หน้าแรกเริ่มจากวันที่กึ่งกลาง สรุปเงินหักออม เงินรวม เงินได้ และเงินจ่าย แล้วเข้ามุมมองรายวันทันที ไม่มีคำทักทายหรือแถวปุ่มลัด เมนู + รวมรายจ่าย รายได้ และกันออม หากมีหลายเป้าหมายจะเลือกเป้าหมายก่อนกันออม มือถือใช้ปุ่ม + ในแถบล่าง ส่วนเดสก์ท็อปใช้ปุ่มลอยมุมล่างขวา

เป้ารายวันเป็นค่าเดียวต่อผู้ใช้ ใช้เทียบทุกวันที่เลือก ตั้งต้น 0 (ไม่ตั้งเป้า) ไม่คำนวณตามงบรายเดือน และไม่เปลี่ยนธุรกรรมหรือยอดออม บันทึกเมื่อ Supabase ยืนยันเท่านั้น หากการบันทึกผิดพลาดมิเตอร์ยังคำนวณจากเป้าเดิม งบรายเดือนยังเป็นแผนรายจ่ายแยกต่างหาก

ตรวจด้วยมือ: เปิดบนมือถือแล้วตรวจว่าเห็นแถบรายวันโดยไม่ผ่านคำทักทาย แตะ + แล้วลองทั้งสามประเภท ตั้งเป้า 150 บาท รีโหลดแล้วตรวจว่ายังเป็น 150 เปลี่ยนงบเดือนแล้วเป้าต้องคงเดิม ปิดเครือข่ายแล้วลองเปลี่ยนเป้า ต้องแจ้งว่ายังไม่ยืนยัน
