# หน้าแรกตามวันที่และรอบเดือน

หน้าแรกเลือกวันที่ย้อนหลังได้ถึงปี 2000 และเริ่มที่วันนี้เสมอ ยอดเงินรวมคือยอดตามรายการที่ยังใช้งานอยู่จนถึงวันที่เลือก เงินที่แยกออมเป็นส่วนหนึ่งของเงินรวมอยู่แล้ว จึงคำนวณเงินเหลือใช้เป็น `เงินรวม − เงินแยกออม` โดยไม่บวกเงินออมซ้ำ

ผู้ใช้เลือกวันเริ่มรอบได้ 1–28 ค่าเริ่มต้นคือวันที่ 1 ตัวอย่างวันที่ 20 ทำให้รอบ 20 ตุลาคม–19 พฤศจิกายน รายรับ รายจ่าย และงบในหน้าแรกใช้รอบนี้ งบยังเป็นเกณฑ์เปรียบเทียบและไม่หักเงินรวม

มุมมองมี 4 ช่วง:

- รายวัน: เป้ารายวันจากงบรวม ÷ จำนวนวันในรอบ, รายการของวันที่เลือก, สัดส่วนหมวด และรายรับ–รายจ่ายแยกประเภท
- รายสัปดาห์: อาทิตย์–เสาร์ เปรียบเทียบแต่ละวันกับสัปดาห์ก่อน
- รายเดือน: รายรับ รายจ่าย เปอร์เซ็นต์งบรวม และยอดเหลือ/เกินของแต่ละก้อนงบ
- รายปี: รายรับ–รายจ่ายของ 12 รอบ และเงินออมสะสม ณ สิ้นแต่ละรอบ

เงินคืนหักรายจ่ายของวันที่/รอบที่ได้รับคืน การโอนและการกันเงินออมไม่เป็นรายจ่าย กราฟใช้ NUMERIC จาก Supabase และแปลงเป็นสตางค์จำนวนเต็มใน client

## Manual acceptance

1. เปิดภาพรวมและตรวจว่าวันเริ่มต้นเป็นวันนี้ กดย้อนหนึ่งวันแล้วเช็กยอดและรายการ
2. ตั้งรอบเป็นวันที่ 20 ตรวจช่วงวันที่บนบัตรและสรุปรายรับ–รายจ่ายในรอบ
3. เปิดรายวันทั้ง 3 แถบ ตรวจมิเตอร์ รายการ pie chart และประเภทรับ–จ่าย
4. เปิดรายสัปดาห์ ตรวจว่ามี อา.–ส. และสองชุดข้อมูล
5. เปิดรายเดือน ตรวจยอด `ใช้ / งบ`, เปอร์เซ็นต์ และยอดเหลือหรือเกินรายก้อน
6. เปิดรายปี ตรวจกราฟรับ–จ่ายและเส้นเงินออมทั้งบนมือถือและเดสก์ท็อป
7. ปิดเครือข่ายแล้วเปลี่ยนวันเริ่มรอบ ต้องไม่แสดงว่าบันทึกสำเร็จ

การทดสอบอัตโนมัติครอบคลุมสิทธิ์ authenticated/anonymous/ข้ามผู้ใช้ รอบวันที่ 20 เงินคืน เงินออมไม่บวกซ้ำ 7 วันเต็ม การเลือกวันที่อนาคต และ responsive Playwright ทั้งสองขนาด
