# Home notebook layout

Home uses an original pencil-and-watercolor illustration of the duck leaning on a flower-lined notebook edge. The transparent artwork is stored as WebP for loading speed; the generated PNG remains in the workspace image library. The gauge marker uses painted duck artwork rather than a geometric face. Date controls, cycle totals, and time-range tabs share one compact sheet. Four totals stay on one row on mobile; forecast and actual financial calculations are unchanged. Whole baht amounts omit trailing zeros, while fractional baht retain two decimal places.

The daily gauge and transaction list sit directly on the cream page without nested panels. The moving duck remains attached to the gauge track. Flowers and a sprout anchor the lower edge. Date selection, cycle settings, privacy toggle, daily goal edits, income categories and historical transaction edits remain available.

Layout checks verify that the first daily transaction fits above the fixed mobile navigation on a 390 × 844 viewport, totals align on one row, the page has no horizontal overflow, and the entry button stays centered. Existing financial workflows are checked on both mobile and desktop using mocked responses. Production checks also use mocked data.
