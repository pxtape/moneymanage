# หมวดรายได้และรูปหมวดธีมน้องเป็ด

เพิ่มหมวดรายได้ 8 แบบ: เงินเดือน รับจ้าง ขายของ โบนัส ดอกเบี้ยและลงทุน ค่าเช่า เงินที่ได้รับ และรายได้อื่น ๆ รายการเก่าไม่มีหมวดจะคงเป็นไม่ระบุหมวด ผู้ใช้เลือกจัดหมวดย้อนหลังทีละรายการได้โดยไม่เปลี่ยนยอดเงิน อนุญาตล้างหมวดในรายการเก่าได้

## การจัดเก็บ

เพิ่มเฉพาะ `transactions.income_category_code` กับชื่อหมวดที่เก็บ ณ ตอนเลือก ไม่แก้ไขฟังก์ชันเดิม `write_finances`, `moneyspace_snapshot`, `moneyspace_home` หรือ trigger เดิม

API `moneyspace_write_income` ใช้การตรวจยอด สิทธิ์ การล็อก การตรวจ version และ request key ของระบบเดิม แล้วเพิ่มข้อมูลหมวดภายในธุรกรรมฐานข้อมูลเดียวกัน หากข้อมูลหมวดผิดพลาด ทั้งการบันทึกยอดและหมวดจะ rollback พร้อมกัน คำขอซ้ำใช้ผลเดิมโดยไม่สร้างรายการหรืออัปเดตข้อมูลซ้ำ ประวัติเดิมบันทึกการเปลี่ยนยอดและการจัดหมวดให้ตรวจสอบได้ รายการที่บันทึกผ่าน client เก่ายังคงอ่านได้

API รายงานรุ่นเสริมอ่านผลเดิมแล้วเพิ่มชื่อหมวดรายได้เฉพาะรายการและข้อมูลแยกประเภท ยอดเงินรวม รายได้ รายจ่าย และงบใช้สูตรเดิมและ RLS เดิม ไม่มีการจัดหมวดรายการเก่าอัตโนมัติ

## รูปและการเคลื่อนไหว

ใช้รูปหมวดลายเส้นสีน้ำตาล พื้นเหลืองเนย และน้องเป็ดสำหรับหมวดทั่วไป แทนการแสดง emoji ในหน้าจด รายการ งบ กราฟ และตัวเลือกรูปหมวด รหัสรูปเดิมยังคงเก็บไว้เพื่อรักษาข้อมูลย้อนหลัง เลือกรูปใหม่จากตั้งค่าและหมวดได้

มิเตอร์มีหน้าน้องเป็ดเคลื่อนรอบวงตามสัดส่วนเป้ารายวัน มีการเอียงหน้าเล็กน้อยและเคารพ reduced motion เปอร์เซ็นต์และข้อมูลสำหรับ screen reader ยังอยู่ครบ

## ตรวจรับ

1. เปลี่ยนเป้ารายวัน สังเกตหน้าน้องเคลื่อนตามระดับการใช้เงิน
2. กด + → รายได้ เลือกหมวดและบันทึก ต้องไม่ยืนยันก่อนเซิร์ฟเวอร์ตอบ
3. เลือกวันเก่าที่มีรายได้ไม่มีหมวด → รายการ → แก้ไข → เลือกเงินเดือนหรือรับจ้าง ตรวจว่ายอดเท่าเดิมและหมวดจำหลังเปิดใหม่
4. ดูแถบรับ–จ่ายรายวัน ตรวจการรวมยอดตามหมวดรายได้
5. ตั้งค่าและหมวด → เปลี่ยนรูป ตรวจชื่อและการจัดหมวดของประวัติเก่ายังคงเดิม
6. ตรวจหมวดและมิเตอร์ในธีมสว่าง ชมพู และเข้ม
