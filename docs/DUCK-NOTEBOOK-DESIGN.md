# สมุดจดเงินของน้องเป็ด

นำการศึกษาหน้าทางการของ [SET Happy Money](https://www.set.or.th/happymoney/app.html), [Money Lover](https://moneylover.me/), [喵喵记账](https://apps.apple.com/cn/app/id1483024444) และ [แนวทางธีม LINE](https://creator.line.me/en/guideline/theme/) มาปรับให้เข้ากับโครงสร้าง MONEYSPACE ที่ผู้ใช้ตรวจแล้ว: เริ่มที่วันที่และสรุปเงินกระชับ จดผ่าน + เดียว และกราฟรายวันถึงรายปี

## อัตลักษณ์

ตัวละครวาดใหม่จากภาพตุ๊กตาที่ผู้ใช้ส่งสองรูป: เป็ดสีเหลืองนวลในหมวกขาวหูกระต่ายสั้น แก้มชมพู ปากส้ม ผ้าพันคอตาราง และหางสั้น มี 6 ท่า: ทักทาย จดเงิน กอดกระปุก ถือกราฟ ดื่มชา และหันหลัง ใช้ภาพโปร่งใส WebP แผ่นเดียวขนาดประมาณ 194 KiB ทุกจุดใช้ภาพเดียวร่วมกัน ไม่โหลดซ้ำแยกท่า ภาพต้นฉบับของผู้ใช้ไม่ถูกเผยแพร่ใน repository

ธีมสว่างเริ่มต้นเป็นครีม–เหลืองเนย–เสจ ใช้ตัวหนังสือสีน้ำตาลเข้ม ธีมชมพูเป็นขนมชมพู ส่วนธีมเข้มเป็นโกโก้ โทนตัวเลขยังมีความต่างจากพื้นชัดเจน แยกสีชุดเปรียบเทียบเป็นเสจกับชมพูกุหลาบ พร้อมชื่อผู้ใช้กำกับ

## จุดที่ปรับ

- โลโก้ หน้าเข้าสู่ระบบ และ sidebar มีตัวละครประจำแอป
- หน้าแรกคงลำดับวันที่ → สรุปเงิน 4 ค่า → ช่วงเวลา → กราฟ/รายการ ไม่มีคำทักทายหรือแบนเนอร์เพิ่ม
- เมนู + เป็นแผ่นเลือก 3 รายการ พร้อมภาพจด รับเงิน และออม
- มิเตอร์รายวันยังแยกเป้าส่วนตัวจากงบเดือน
- หมวดที่ผู้ใช้กำหนดยังคงชื่อและ emoji เดิม ไอคอนนำทางใช้ลายเส้นและป้ายข้อความสม่ำเสมอ
- ตัวละครในข้อความยืนยันแสดงหลังเซิร์ฟเวอร์ยืนยันเท่านั้น ไม่บังยอดเงินหรือกราฟ
- แอนิเมชันพยักหน้าทำงานครั้งเดียว และเคารพ prefers-reduced-motion
- ไม่มีการเปลี่ยนสูตรเงิน สิทธิ์ หรือข้อมูลใน Supabase

## ตรวจรับด้วยมือ

1. เปิดหน้าแรกบนมือถือ ตรวจว่าวันที่ เป้ารายวัน และ + เข้าถึงได้รวดเร็ว
2. เปิด + ทดลองรายจ่าย รายได้ และกันออม แล้วตรวจการปิดเมนู/โฟกัส
3. เปลี่ยนธีมสว่าง ชมพู เข้ม ตรวจหน้าหลัก กราฟ ฟอร์ม และเลือกธีมแล้วยังจำหลังรีโหลด
4. แก้รายการย้อนหลังและเป้ารายวัน ตรวจว่าตัวเลขเปลี่ยนเฉพาะหลังยืนยัน
5. เปิดกราฟเปรียบเทียบ ตรวจชื่อชุดข้อมูลและสีที่แยกกันได้
6. เปิด reduced motion และตรวจว่ารายการยังอ่านและใช้งานได้
